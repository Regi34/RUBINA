Taruh file musik latar anak-anak bebas hak cipta (CC0 / YouTube Audio Library) di folder ini dalam format .mp3.
Contoh: happy_ukulele.mp3, playful_bells.mp3

Jika folder ini kosong saat GitHub Actions berjalan, Video Editor Agent otomatis membuat musik latar lembut/ceria secara prosedural menggunakan FFmpeg agar pipeline tetap berjalan tanpa error.
